# 개발 환경 설정

## 📋 요구 사항

개발을 시작하기 전에 다음을 준비하세요.

| 요구 사항 | 버전 | 필수 여부 | 설명 |
|----------|------|---------|------|
| **JDK** | 21 이상 | ⭕ 필수 | Java Development Kit |
| **Maven** | 3.6 이상 | ⭕ 필수 | IntelliJ에 내장돼 있습니다 |
| **MySQL** | 8.0 이상 | ⭕ 선택 | DB를 안 쓰면 `data/` 폴더 사용 |
| **Git** | 최신 | ⭕ 필수 | 저장소 클론 및 커밋 |
| **IntelliJ IDEA** | 최신 | 권장 | 또는 다른 Java IDE |
| **Kakao Developers** | — | ⭕ 필수 | 지도 API 키 발급 |

## 1️⃣ 저장소 클론

```bash
git clone https://github.com/mandur23/SafeFood.git
cd SafeFood
```

## 2️⃣ IDE에서 프로젝트 열기

### IntelliJ IDEA

1. **File → Open...**
2. **SafeFood** 폴더 선택
3. **`pom.xml`을 프로젝트로 열기** 선택
4. Maven 의존성이 자동으로 다운로드됩니다

```bash
# 터미널에서 확인
mvn clean compile
```

## 3️⃣ 데이터 저장소 선택

### A) MySQL 사용 (권장)

#### 3-1. MySQL 설치

```bash
# macOS (Homebrew)
brew install mysql

# Windows: MySQL 공식 설치 파일 다운로드
# https://dev.mysql.com/downloads/mysql/

# Linux (Ubuntu)
sudo apt-get install mysql-server
```

#### 3-2. MySQL 서버 시작

```bash
# macOS
brew services start mysql

# Windows: MySQL Command Line Client 실행

# Linux
sudo systemctl start mysql
```

#### 3-3. 데이터베이스 생성

```bash
mysql -u root -p
```

```sql
CREATE DATABASE safefood DEFAULT CHARACTER SET utf8mb4;
SHOW DATABASES;  -- safefood가 보이면 성공
EXIT;
```

### B) MySQL 미사용 — `data/` 폴더

프로젝트 루트에 이미 `data/public/`, `data/private/` 폴더가 있습니다.

| 폴더 | 용도 | 커밋 |
|------|------|------|
| `data/public/` | 공통 데이터 (알레르기·기분·메뉴 등) | ⭕ |
| `data/private/` | 개인 데이터 + 팀 서버 데이터 | ❌ (`.gitignore`) |

> MySQL 없이 시작해도 됩니다. 앱 데이터는 `data/` 폴더에 파일로 저장됩니다.

## 4️⃣ 설정 파일 작성

프로젝트 루트에 `config.properties` 파일을 만듭니다.

```bash
# config.properties.example을 복사해서 시작
cp config.properties.example config.properties
```

### MySQL을 사용할 경우

```properties
db.url=jdbc:mysql://localhost:3306/safefood?serverTimezone=Asia/Seoul&characterEncoding=UTF-8
db.user=root
db.password=본인_MySQL_비밀번호

map.api.key=발급받은_카카오_API_키

socket.host=localhost
socket.port=5000
```

### MySQL을 안 쓸 경우

```properties
db.url=
db.user=
db.password=

map.api.key=발급받은_카카오_API_키

socket.host=localhost
socket.port=5000
```

## 5️⃣ Kakao Map API 키 발급

1. **[Kakao Developers](https://developers.kakao.com/)** 접속
2. **로그인** (없으면 회원가입)
3. **내 애플리케이션 → 애플리케이션 추가**
   - 앱 이름: `SafeFood`
   - 앱 종류: 선택
4. **애플리케이션 선택 → JavaScript 키 복사**
5. `config.properties`의 `map.api.key`에 붙여넣기

## 6️⃣ 테이블 생성 (MySQL 사용 시만)

### Setup Wizard로 자동 생성 (권장)

```bash
# JavaFX 창으로 실행 (권장)
mvn javafx:run -Pwizard-fx

# 또는 콘솔로 실행
mvn compile exec:java -Pwizard
```

Setup Wizard가 테이블을 자동으로 생성합니다.

### 수동으로 생성

`README.md`의 [[🗄️ 데이터베이스 스키마]] 섹션의 SQL을 MySQL에서 실행합니다.

## 7️⃣ 실행

### 기본 실행

```bash
mvn compile exec:java
```

### JAR로 빌드 후 실행

```bash
mvn clean package                    # safefood.jar 생성
mvn dependency:build-classpath -Dmdep.outputFile=cp.txt
java -cp "target/classes;$(cat cp.txt)" com.safefood.Main
```

### IntelliJ에서 실행

1. `src/main/java/com/safefood/Main.java` 열기
2. `main()` 메서드 옆 **▶ 버튼 클릭**

### 그룹 추천 테스트 (여러 창)

```bash
# 터미널 1: 방장 (서버 역할)
mvn compile exec:java

# 터미널 2: 참여자 1
mvn compile exec:java

# 터미널 3: 참여자 2
mvn compile exec:java
```

IntelliJ에서 여러 창을 동시에 띄우려면:
- **Run → Edit Configurations...**
- **Modify options → Allow multiple instances** 체크
- ▶ 버튼으로 여러 개 실행

## 🛠️ Maven 자주 쓰는 명령

| 명령 | 설명 |
|------|------|
| `mvn clean` | `target/` 폴더 삭제 |
| `mvn compile` | 소스 코드 컴파일 |
| `mvn test` | 테스트 실행 (`src/test/java`) |
| `mvn package` | JAR 파일 생성 |
| `mvn compile exec:java` | 앱 실행 |
| `mvn javafx:run -Pwizard-fx` | Setup Wizard 실행 (창) |
| `mvn clean install` | 로컬 저장소에 설치 |
| `mvn dependency:tree` | 의존성 트리 표시 |

## ⚠️ 자주 마주치는 문제

### Q: "JDBC Driver not found" 오류

**A:** Maven이 의존성을 못 받았을 수 있습니다.
```bash
mvn clean install
mvn dependency:resolve
```

### Q: "config.properties not found"

**A:** 프로젝트 루트에 `config.properties` 파일이 없습니다.
```bash
cp config.properties.example config.properties
# 값을 본인 환경에 맞게 수정
```

### Q: MySQL 포트 충돌 오류

**A:** 이미 다른 프로세스가 포트를 사용 중입니다.
```bash
# macOS: 프로세스 확인
lsof -i :3306

# 프로세스 ID 확인 후 종료
kill -9 <PID>

# MySQL 재시작
brew services restart mysql
```

### Q: 소켓 포트 5000이 이미 사용 중

**A:** `config.properties`에서 다른 포트로 변경
```properties
socket.port=5001
```
